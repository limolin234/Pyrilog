# pyrilog

pyrilog是一种面向光电热共同仿真的基于python的硬件描述与仿真方案。作者认为，大规模仿真最有效率的方案就是MNA，故pyrilog在设计哲学上很多都基于MNA的特性。显然现有的spice/verilogA其核心算法也就是MNA,然则spice语法过于麻烦，verilogA也不原生支持光与相关的复数运算，故本项目致力于基于python在语言上统一光电热的支持。受到ehpic_model通过spice建模光的启发，同时考虑到MNA仿真后端的复杂性，本项目最终决定采用生成spice/verilogA代码从而直接借用现有MNA后端的方案，这意味着本项目的语言与特性支持会受到spice/verilogA语言及其仿真器的限制，而益处是能复用后端并能生成可审计的中间spice/verilogA文件。

## 语言基本构成

同其他仿真方案相同，pyrilog分为物理对象抽象、器件/子网路建模、主网络建模、仿真控制这几大部分。其中物理对象主要基于MNA特性进行建模，器件/子网路通过运算符重载/统一抽象/参数化等手段与特性实现简明直观便于扫描参数的特性，仿真控制方面则通过面向对象操作器件/网络参数与输出单位等，从而实现高效的参数扫描与输出控制。

### 物理抽象

为了便于MNA分析，物理抽象做出了牺牲。电部分最终尽可能保留spice原有的全部功能，光部分经过考量只能分析单一频率的复数传递而无法支持频率分布的真实传递，热部分无法使用有限元只能把每个器件抽象成热节点。
